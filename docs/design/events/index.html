Pod events sidebar: design options

Click a pod and a right-hand sidebar shows its 5 latest events, paginated. Each mockup is interactive (paging, close, expand).

Chosen: pod-drawer.html (A's drawer and rows, with C's header and tabs). The options below are kept as a record.

  1. A: Overlay drawer: the densest view, numbered pages, offset pagination.
  2. B: Docked timeline: doesn't cover the table, timeline view, cursor pages that stay stable as new events arrive.
  3. C: Tabbed pod panel: Events / Logs / Details tabs, a Warning filter, ready for the logs feature.
